# Реальные входы исходного учебного проекта

Здесь полные исходные таблицы, а не уменьшенный демонстрационный пример:

- [churn_features.parquet](<churn_features.parquet>): 198 578 абонентов, subscriber_key + 10 признаков HW5;
- [churn_truth.csv](<churn_truth.csv>): 200 000 синтетических абонентов, subscriber_key, churn_day_index, churned. Из эталона используется **только churned**; churn_day_index не подаётся модели;
- [source_manifest.json](<source_manifest.json>): размеры и SHA-256 неизменённых файлов, относительные пути к исходникам в первоначальной учебной директории. Для запуска эти внешние пути не нужны: оба файла включены в репозиторий.

Генератор TDG 1.0.0, уровень S, seed=20260827, начало 2025-10-01, 90 дней. В [паспорте](<../provenance/tdg_passport.json>) указаны параметры. README исходного генератора (локальный lab1/tdg_generator/README.md, строки 6–9) прямо указывает: данные полностью синтетические, не содержат ни одной реальной записи, оператор условный. Ключи вида SUB000000000 — искусственные идентификаторы, не персональные данные.

Признаки построены по очищенным CDR, tickets и telemetry. Окно: [2025-11-30, 2025-12-30), предыдущее окно [2025-10-31, 2025-11-30). Одна строка на наблюдавшегося абонента; без CDR за всю поставку абонент не представлен. Полные сырые CDR (гигабайты) для повторного обучения не нужны и не публикуются. Их преобразование уже выполнено HW5; формулы сохранены в [паспорте признаков](<../provenance/features_report.md>).

Покрытие: у всех 198 578 строк признаков есть метка; 1422 дополнительных строки эталона не используются. Ключи уникальны в обеих таблицах.

**Ограничение:** churned обозначает отток за всю поставку; окно признаков может быть позже фактического ухода. Здесь сохраняется исходная ретроспективная классификация, не прогноз будущих 30 дней. Для такого прогноза нужны исторические срезы и метки строго после cutoff, как обсуждается в [протоколе оценки](<../docs/evaluation_protocol.md>). Не следует интерпретировать высокую AUC этого эксперимента как качество прогнозирования.
