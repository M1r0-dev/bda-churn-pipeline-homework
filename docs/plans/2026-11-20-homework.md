# План выполнения ДЗ: конвейер классификации оттока

## Спецификация и исходники
Требования: рефакторинг load_data/preprocess/train_model/evaluate, JSON-конфиг, logging, идемпотентность, русские README/отчёт/схема, реально проверенный Docker и публичный GitHub. Исходник: локальный InnopolisBigData6_1.ipynb (задание в последней ячейке); признаки HW5, синтетический TDG S seed 20260827, метка churned из HW4. Другого явного проекта «5.2» нет. Исходные файлы сохраняются локально без изменений; нет исходной Git-истории. Репозиторий ограничен lab2.

## Архитектура и ограничения
Один pipeline.py и config.json. Сохраняем RandomForest, десять исходных признаков, заполнение нечисловых значений/inf/NaN константой 0, StandardScaler и стратифицированное 60/20/20, seed=42, threshold=0.5. Фит преобразований только train; сохранение полного sklearn Pipeline. Это ретроспективная классификация churned, а не будущего churn_30d: временной leakage исходной постановки не маскируется высокой AUC. Идемпотентность: повторное обучение и безопасная перезапись стабильных файлов без кеша. Параллельные писатели в одну папку не поддерживаются.

## Задачи, границы и зависимости
### T1 — ML-конвейер (агент ml-engineer)
Depends: нет · Parallel-group: A
Files: pipeline.py, config.json, tests/test_pipeline.py.
Consumes: data/churn_features.parquet + data/churn_truth.csv.
Produces: load_data(config)->DataFrame, preprocess(frame, config)->dict сплитов, train_model(X,y,config)->Pipeline, evaluate(model,splits,config)->dict, run_pipeline(config_path)->dict; CLI python pipeline.py --config config.json. Выход artifacts/model.joblib, features.json, metrics.json, manifest.json, splits.csv, pipeline.log.
Steps: написать тесты контракта; убедиться в отказе до реализации; реализовать; python -m unittest discover -s tests -v (все тесты успешны); Lead проверяет и коммитит интеграцию.
Проверки: уникальность/непустые ключи, оба класса, пропуски/inf, исключение служебных полей, непересечение сплитов, scaler fit только train, сериализация, повторный запуск и exit 1 при ошибке. SHA-256 данных/кода/конфига + версии пакетов в manifest; время только в логах.
